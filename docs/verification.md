## TDD 边界

按用户确认的边界逐步实现：

1. 课程目录测试先在参考数据上失败，再实现三组各 9 个 Kubernetes 主题。
2. 场景／示例测试先因导出文件不存在失败，再实现 54 份带前提和预期的可下载示例。
3. DOM 学习流程先因新课程尚未接入界面失败，再完成导航、搜索和场景示例面板。
4. 知识图谱反向关联测试先失败，再把内容声明的关联归一化为无方向关系。

保留原项目图解与运动的回归边界；额外验证播放、暂停、末阶段停留、重置、主题与进度保存、无效本地进度容错。

## 静态与离线验证

- TypeScript 严格类型检查覆盖三条路径的课程与场景。
- 课程检查：27 个主题、54 个场景、216 个阶段，合法参与者编号、关系类型、来源和关联目标，示例输出与源内容对应。
- IsoKit 实际渲染：216 个阶段、四个参与者、箭头／中断语义、暂停、减少动态效果、投影与标签边界。
- 运动回归：实际时间进度、折点、暂停恢复、速度变化、延迟帧、清理与末阶段完整停留。
- JSDOM 流程使用真实课程、图解和应用 bundle；媒体偏好与播放时间为环境边界替代，不能替代浏览器布局验收。
- 17 个 YAML 文件、25 个资源对象通过 PyYAML 离线解析；所有 Shell 示例通过 `sh -n`。没有执行任何集群命令。
- 41 个 Kubernetes 官方来源链接检查均返回 HTTP 200，明细见 `source-links.json`；可用链接不等于其内容会永久保持不变。

## 验证限制

没有连接真实 Kubernetes 集群；没有验证调度、准入、插件或应用在某个发行版上的实际结果。没有部署到外网。教学模型、离线检查与浏览器结果均不能代替真实集群实验和业务验收。
