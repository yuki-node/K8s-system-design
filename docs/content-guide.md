# 内容范围与核查说明

课程整理日期：2026-11-05。以 Kubernetes 官方概念、任务和 API 文档为依据，选择稳定 API 与通用机制，不将某个最新小版本或某种网络实现当作所有集群的行为。每个主题的来源页提供直接文档链接。

## 教学模型

27 个主题分为基础与架构、应用与流量、运维与排障，每组 9 个。54 个独立场景共 305 个阶段，主流程按机制需要展开为 6–12 个阶段。一个逻辑阶段可能压缩多轮控制循环，图解不是实际事件回放、时间线或物理集群拓扑。

逻辑参与者按场景需要定义，可以是组件、资源、集合或观测对象。实线箭头表达请求／数据传递；虚线表达控制／条件检查；拒绝表示请求被拒；中断表示未送达；内部操作不画传递线；对照关系没有方向。教学图不据插画数量推断节点数、Pod 数或网络跳数。

## 重点边界

- spec 被接受不代表运行或业务成功；status 与事件是组件观察。
- 容器重启与新 Pod 替换不同；Running 与 Ready 不同。
- startup 成功前不执行其他两种探针；readiness 失败本身不重启容器。
- Service selector 对应 Pod 标签；EndpointSlice 是后端视图，数据面不逐请求查询 API。
- Service port、targetPort 与进程监听端口不同；DNS 成功不证明连接可用。
- requests、CPU 限制与内存 OOM 分开；HPA CPU 利用率依赖相关 requests 与指标 API。
- Deployment 超时不会默认自动回滚；StatefulSet 不实现数据库复制；Job 不保证业务恰好一次。
- ConfigMap/Secret 环境变量、普通投射卷与 subPath 更新行为不同；Secret 编码不是加密。
- NetworkPolicy 依赖支持它的网络实现，允许规则叠加，连接要考虑源出站和目标入站。
- RBAC 授权、Pod 安全准入与应用鉴权是不同边界；warn/audit 不等于 enforce。
- drain 是维护流程，PDB 不保护全部中断；--ignore-daemonsets 不会删除守护 Pod。
- etcd 快照不包含后端业务卷内容；恢复要验证应用数据，升级须遵循实际发行版路径和组件版本约束。

## 实验前提

站点不执行 kubectl，也不持有集群凭据。示例均说明前提与预期，完整 YAML 和命令可单独下载。`examples/lab.yaml` 为可选入门实验，创建 demo/web Deployment 与 Service。部分实验需要 NetworkPolicy CNI、入口控制器、存储驱动或 Metrics Server 等额外组件。

涉及实际节点维护、升级、etcd 恢复的主题提供机制和只读盘点，不提供盲目执行的通用生产脚本。所有例子应在自己的实验环境核对身份、命名空间、版本和插件。生产镜像还应按团队供应链和补丁流程固定与更新。

## 验证范围

课程类型检查验证结构，内容检查验证完整性、关系编号和导出文件，图解检查验证 全部 305 个阶段的实际 IsoKit 输出与动画语义，DOM 流程检查验证导航及状态变化；真实浏览器检查补充布局与交互。它们不证明 Kubernetes 协议或生产环境正确，也不替代真实集群实验。YAML 经离线结构解析，不宣称已由真实集群服务端准入或运行验证。
