## TDD 边界

按用户确认的边界逐步实现：

1. 课程目录测试先在参考数据上失败，再实现三组各 9 个 Kubernetes 主题。
2. 场景／示例测试先因导出文件不存在失败，再实现 54 份带前提和预期的可下载示例。
3. DOM 学习流程先因新课程尚未接入界面失败，再完成导航、搜索和场景示例面板。
4. 知识图谱反向关联测试先失败，再把内容声明的关联归一化为无方向关系。

保留原项目图解与运动的回归边界；额外验证播放、暂停、末阶段停留、重置、主题与进度保存、无效本地进度容错。

## 真实浏览器

使用浏览器查看用户补充的 Protocol Explorer，核对三栏界面、等距底网格、细边框、单色立体设备、分步与下方轨迹的参考形式。

本机 HTTP 预览返回 200。浏览器分别检查宽屏与窄屏布局、目录展开／收起、探针搜索、主题选择、主流程／故障切换、下一步、示例复制（显示成功反馈）、YAML 下载入口与深色主题。发现长说明在短屏画布中裁切，增加桌面行高并让说明不收缩后再次查看。

截图：`preview-desktop.png`、`preview-dark.png`、`preview-mobile.png`。窄屏检查为实际预览面板尺寸，未声称覆盖所有手机型号。
